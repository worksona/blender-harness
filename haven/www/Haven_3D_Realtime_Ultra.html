Connect directly to your Home Assistant server over its WebSocket API. Discover devices and sensors, assign them to model rooms, then use the live controls.

Use a browser-reachable URL. From an HTTPS page, your Home Assistant endpoint must also use HTTPS/WSS.
Create under Home Assistant → Profile → Security → Long-lived access tokens. The token is held in memory for this page session, not saved to disk. Never share it or publish it with this HTML file.
For the most straightforward deployment, serve this file from Home Assistant's /config/www folder (available at /local/...) or use a secure HTTPS host that can reach your Home Assistant server. The browser connects directly; no third-party service handles your token.
